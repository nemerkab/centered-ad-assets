# Start/Apply Meta creatives

Static Meta ads driving traffic to `/start/apply`.

| Path | Purpose |
|---|---|
| `CONCEPTS.md` | 10 concepts + Meta primary/headline/description copy |
| `build.py` | Regenerates HTML → PNG |
| `html/` | Source pages (on-brand Inter / dark monochrome) |
| `images/` | Drop these into Meta — `*-1x1.png` (1080²), `*-4x5.png` (1080×1350), `*-9x16.png` (1080×1920 Reels/Stories) |

```bash
python3 build.py
```
